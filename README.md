# Potwillow 1.0 TEST
Native Java/Canvas Android 8+ Yosenabe straight-move sum-pot puzzle.

Select a numbered circle, then tap a gray cell in its row or column to set its straight destination. Routes cannot cross, overlap or pass through another original circle. A route may pass through gray pots on its way. Every pot must receive at least one circle, and its gold total must equal the sum of its arriving circle values. Each level has four circles and three labeled two-cell pots; all pot totals are shown. Twelve distinct 4x4 layouts each have a unique set of four exact destinations. Original circles and destination dots remain visible as the movement diagram. Select a circle again to change its destination; undo/reset restores earlier choices.

Saved pot palette and cell guides, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, account or requested permissions. Settings and completed-puzzle marks stay on device. External studio link opens browser.

Independent Java coordinate-range and cell-set checks agree with production stepped-path bitmasks on all 83521 partial or full destination assignments per puzzle (each of four destinations is blank or any of 16 cells). Unique full destinations, bounds, circle selection, solve, undo and replay pass. Adapter navigation, saved settings, privacy, circle/destination taps, next, levels and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Current 803-entry registry, 119 partial recovered README records and semantic review of all 139 cards in the exact Mossmaze cumulative stage found no Yosenabe match.
